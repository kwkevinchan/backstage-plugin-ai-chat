# Backstage plugin: AI chat

> **Unofficial.** This project is a community plugin. It is not affiliated with,
> endorsed by, or supported by the Backstage project.

**Status: under construction.** A chat for [Backstage](https://backstage.io)
in which a signed-in user talks to an LLM, and the LLM can call the actions of
the Backstage actions registry as that user. Actions that only read run at
once. Every other action waits until the user approves it in the chat.

The full README comes with the first release.
